# Invest

人民币 A 股研究、日频策略验证与历史模拟账本。**v0.1.0 是可在本机运行的中文网页工具；演示数据为合成数据，尚未完成真实行情接入验证。**

## 启动

需要 Python 3.11 或以上。运行不需要安装第三方 Python 包、不需要 Node、不需要模型 API Key。

```bash
python -m invest --open
```

在项目根目录运行，浏览器打开 `http://127.0.0.1:8765`。Windows 可双击 `start.bat`。端口被占用时：

```bash
python -m invest --port 8766 --open
```

按 Ctrl+C 停止。默认 `.invest/` 保存导入行情、回测记录、模拟账户及研究笔记；重启后保留。不要把该私密目录提交或上传。可用 `--data-dir` 指定自己的本地目录。

## 第一轮体验

1. 点击“载入合成示例”，查看两只代码格式示例的 140 个合成交易日。
2. 在研究页查看价格变化、波动率、回撤、均线状态和反证；指标描述历史，没有上涨概率。
3. 在回测页选择代码、均线参数和初始模拟资金，检查费用参数并勾选固定情景确认。
4. 查看策略与买入持有基准的曲线、实际评价日期、成交/拒单明细。前置数据用于预热，结果不含预热期收益。
5. 创建模拟账户，选择历史日期、方向、数量，填写交易理由。尝试同日买入后卖出，系统会按 T+1 拒绝。
6. 在研究笔记中填写假设、证据、反证、失效条件与来源链接，保存供后续复盘。
7. 导出研究 JSON，保留数据、参数、版本、指纹和回测结果。导出不包含私人账户或笔记。

## 数据接入

详细字段、CSV 例子和日历要求见 [数据格式](docs/DATA_FORMAT.md) 与 [examples/README.md](examples/README.md)。CSV 必须确认未复权价格、成交量以股计；不要直接把前复权行情或“手”为单位的数据套入。

Tushare 使用服务器环境变量 `TUSHARE_TOKEN`，页面不接收或显示 Token。官方接口权限由账户决定；使用前自行核对数据供应商权限和费用。程序没有代购数据或付费订阅功能。

```powershell
# 在自己的本地 PowerShell 中设置，勿把真实 Token 发到聊天、仓库或共享文件。
$env:TUSHARE_TOKEN = "你的本地凭据"
python -m invest --open
```

v0.1 的 Tushare 适配器读取日线、复权因子、每日涨跌停价与交易日历，可用于研究导入。**它没有证明完整的历史停牌及公司行动，因此保持未知字段并阻止回测/模拟成交。** 若要回测，需提供来源明确且执行字段完整的 CSV；程序验证格式与一致性，不替数据供应方证明事实真实性。接口适配器目前仅通过模拟响应测试，未使用真实 Token 联调。

## 当前支持与边界

- 范围：沪深主板格式的单只股票日线回测、人民币现金账户、仅做多。研究汇总及模拟账本可以记录多只股票。
- 策略：短均线高于长均线时目标持有，否则目标现金；使用前一交易日收盘信息，在下一明确交易日开盘尝试成交。
- 执行：100 股买入、T+1、方向性涨跌停、停牌/零量、滑点边界、现金含费用检查。一日订单失败会记录原因，不静默延续旧信号。
- 费用：默认值是示例常量情景，用户可改。它不是券商报价，也没有自动重建历史税费变更；佣金已含的费用不要再重复输入。
- 企业行动：未知、因子变化或已知行动区间不执行；尚未处理分红、送转、配股、红利税和真实公司行动现金流。
- 结果：期末仍有持仓按收盘价估值，不伪装已清仓收益；原始价格变化不等于含分红总收益。
- 数据/判断：没有全市场候选池、历史退市覆盖、财报估值、新闻抓取、LLM 研报生成、自动买卖或券商连接。没有盈利能力验证。
- 使用环境：页面适配桌面和手机宽度；本版服务只监听运行电脑的本机地址，未发布公网，也不开放未经认证的局域网访问。

## 从数模项目复用的内容

复用 NCMCM-Modeler-Copilot 的数据先审计、来源指纹、假设/反证/失效条件、简单基准、独立审查与可复现记录流程。金融数据和执行约束独立实现；没有复制竞赛分类器、把模型推荐评分当投资胜率，或启用原项目的 Provider/Solver 通道。原数模库未修改。
