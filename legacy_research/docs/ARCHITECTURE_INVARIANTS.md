# 架构与金融计算约束

## 数据和身份

`invest/data.py` 管理输入解析、日历/字段审计、确定性示例及 Tushare 边界。数据指纹涵盖元数据（排除抓取时间）、原始行情和日历。存储、研究、回测、账本均重新验证指纹。审计的 ready 提示不替代执行器逐字段复核。

证券代码是字符串；金额以人民币计，原始成交价格以元/分计，成交量以股计。来源和单位是供应者的声明，不能把通过结构验证解释为官方真实性认证。关键字段未知保持未知，绝不填成安全的 false/0。

## 执行与账本

`invest/engine.py` 实现有限范围的确定性现金账户模型，并向 `invest/portfolio.py` 提供同一费用和执行函数。引擎只读取截至信号日期已存在的均线输入，下一交易日开盘尝试成交。用于约束模拟成交的当日 OHLC 无法重建真实盘口。

金额使用 Decimal 与逐项分位舍入。无杠杆、无做空、不得出现负现金。买入整手、卖出受 T+1 可卖股数约束。未知停牌/公司行动/限价、缺日历或未支持企业行动不能执行。

模拟账本通过 SQLite 事务串行化资金修改，并追加记录。账户交易日期不得回退，已有持仓所用历史不可悄然换源或改价。估值数据缺失或不兼容返回空值，绝不以买入成本冒充市场价格。

## 应用与隐私

`invest/server.py` 使用 Python 标准库提供本机 API、静态页面、数据与回测持久化。页面不持有数据供应商凭据；Tushare 凭据仅可由服务进程的环境提供，HTTPS 固定目标且禁止重定向。

服务仅绑定本机，验证 Host/Origin/CSRF，并拒绝重复 JSON 字段与非有限值。个人账户/笔记在被 gitignore 的本地数据库。没有券商接口、转账、云同步、真实订单或账户读取。

## 扩展方式

后续引擎适配仍须经过 `ValidatedDataset → 参数/执行规则 → BacktestResult` 的边界。替换底层实现不得悄悄改变一日订单、费用、企业行动、基准或身份规则。加入板块、策略、PIT 基本面、企业行动前，应先制定数据契约和反例测试。
