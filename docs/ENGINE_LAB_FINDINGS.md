# 双引擎实验室：本轮发现与后续执行合同

本记录基于固定合成场景，不能作为真实市场交易规则、费率或投资建议。原始结果见交付包 `reports/cases/*.json`；精确源码、CI和归档身份见 `governance/independent_engine_result.json`。

## 最重要的发现：只比较最终收益会漏掉错误

`day_volume_reuse` 中，同一日声明100股成交容量，连续申请两笔各100股。当前Invest逐单执行函数各自检查总量，两笔都成交；RQAlpha原生匹配器累计占用容量，只成交第一笔。末日价格回到10元时，两者净资产都等于10,000元，但前者是8,000元现金+200股，后者是9,000元现金+100股。只核对最终净值会错把两者当成等价。

`fractional_fees` 中，两边最后现金都为10,098.71元，但中间现金和分项佣金、税费不同。实验室按日、按单、按费用分项检查，因此仍标记DIVERGED。

这不表示原工作台所有研究结果都错误：当前均线回测通常每天只提交有限单个动作。它暴露的是将同一逐单接口扩展到同日多单/多策略时必须明确的共享流动性合同。此前冻结结果不改写。

## 六类实际分歧

| 场景 | Invest | RQAlpha原生路径 | 下一协议必须明确的事项 |
|---|---|---|---|
| 申请300股、声明成交容量150股 | 整笔拒绝 | 部分成交100股 | 全部成交或取消、允许部分成交、剩余单处理 |
| 两笔100股共用100股容量 | 两笔各自通过 | 仅第一笔通过 | 证券/时段级共享容量与多策略顺序 |
| 分项小数费用 | 各项到分取整 | 保留更细精度 | 最低费、累计费、取整时点和容差 |
| 显式过户费用 | 收取声明的演示费用 | 本路径没有单列该项 | 费率有效日期、产品和数据来源，不继承演示参数 |
| 1bp百分比滑点 | 不利方向到分 | 原生百分比价 | 价格最小变动单位与取整方式 |
| 滑点价超出声明OHLC | 拒绝 | 结果可成交 | 数据分辨率与成交价格可行性 |

原始股票成交引擎均未改写来制造一致，报告保留原生成交和原因。本轮并未确定哪种流动性模型在真实市场中更准确；合成日线代理不是真实开盘盘口。

**ENG-05 后续研究：** 独立生成策略信号、不同真实市场环境、冻结未见留出、持续前向模拟，再做独立审阅和用户设备验收。前向证据必须从真正运行时开始积累，不能拿历史补录或CI运行次数代替。
