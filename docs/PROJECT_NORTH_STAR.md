# Invest 的目标

帮助使用人民币资金的个人投资者，把 A 股研究、策略假设、历史验证、风险观察和复盘连接成可追溯工作流。

用户的当前范围是人民币资金，第一阶段优先 A 股；不把美元账户、跨境券商、全自动交易当作前置条件。第一版以沪深主板、日线、单股票历史模拟为明确边界；ETF 和更复杂的组合研究后续再评估。

成功标准是数据有来源、缺失会显式阻断、计算可重现、假设可被反驳、操作和失效原因可理解。收益能力须通过另行冻结的真实样本、样本外检验和前向模拟评价；合成数据及软件单元测试不能证明策略有效。

不以“猜中涨跌”“给分即荐股”或自动下单为第一版目标。用户拥有投资决定；程序不连接券商。金融数据与研究框架的验证质量优先于复杂模型数量。
