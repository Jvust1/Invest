# Invest v0.1 参考来源与交易模型边界

核查日期：2026-09-22。本文记录官方文档、固定上游身份和本项目明确采用的简化情景。实际代码入口为 `invest/data.py`、`invest/engine.py`；数据字段详见 [DATA_FORMAT.md](DATA_FORMAT.md)。

本轮只完成公开文档/README/许可证层面的对标和本地实现验证，没有真实 Tushare 凭据调用、券商连接、实盘交易或真实行情验收。文档阅读不等同于已经具备相应数据权限，也不证明某段历史行情完整。

## 1. Tushare 官方接口

| 接口与官方文档 | 核查到的事实 | Invest v0.1 的采用与限制 |
| --- | --- | --- |
| [`daily`，doc_id=27](https://tushare.pro/document/2?doc_id=27) | 日线为未复权行情；停牌期间不提供数据；`vol` 单位为手 | 已接入研究导入；`vol × 100` 换算为股。不能把缺失日线认作已确认停牌 |
| [`trade_cal`，doc_id=26](https://tushare.pro/document/2?doc_id=26) | 提供交易所、日历日期和开市状态；支持指定交易所和区间 | 按 SSE/SZSE 获取独立日历，检查自然日覆盖并筛选开市日。不能用行情日期集替代日历 |
| [`stk_limit`，doc_id=183](https://tushare.pro/document/2?doc_id=183) | 按证券和日期提供 `up_limit`、`down_limit` | 使用明确上下限，不按股票代码、当前简称或固定比例还原历史上下限 |
| [`adj_factor`，doc_id=28](https://tushare.pro/document/2?doc_id=28) | Tushare 生产的股票复权因子序列 | 用于完整性和变化检测；未用于改写成交价，也不替代分红/送股事件资料 |
| [`suspend_d`，doc_id=214](https://tushare.pro/document/2?doc_id=214) | 每日停复牌信息，包括 S/R 状态和日内停牌时间段 | 尚未接入；需要区分全天与日内停牌、事件持续区间及缺失记录含义，不能由 OHLC 是否存在直接替代 |
| [`dividend`，doc_id=103](https://tushare.pro/document/2?doc_id=103) | 分红送股、实施进度、登记日、除权除息日、派息日和红股上市日等 | 尚未接入；计划与实施需要区分，到账时点与股数变化需要独立建模 |

当前适配器的四项输入并不能证明没有停复牌或公司行动，因此 `suspended`、`corporate_action` 保留未知，真实在线数据只进入研究与审计流程，不能直接执行回测/模拟成交。将来接入另外两个接口也不自动代表所有公司行动已被覆盖；配股、不同税务处理、数据修订与特殊交易机制仍需单独核验。这是本项目根据接口覆盖范围作出的工程限制。

接口积分门槛、频次和授权可能变化，以调用时的官方页面和实际账户权限为准。v0.1 不承诺免费可用或固定调用额度，不自动购买权限；请求失败会明确报错或保留阻断，不回退到虚构行情。

## 2. 上交所现行规则及历史适用日期

已核查上交所发布页和所附规则文本：[《上海证券交易所交易规则（2026年修订）》](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)，上证发〔2026〕41号，2026-04-24 发布，2026-07-06 生效，核查时标示现行有效。发布通知另列暂缓实施条文，不能把正文每一项都默认为已生效。

| 官方条文/事项 | 本项目的对应处理 |
| --- | --- |
| 第 3.1.4 条：交收前卖出限制，回转交易品种另有规定 | 对当前普通股票现金模型采用 T+1：当天买入股份不进入当天可卖数量；不把其他品种的回转交易规则迁移过来 |
| 第 3.3.8 条：竞价买入以 100 股及其整数倍申报，零股卖出另有要求 | 买入限制为 100 股整数倍；零股只允许一次性卖出全部可卖持仓，采用较保守的简化实现 |
| 第 3.3.11 条：A 股价格最小变动单位为人民币 0.01 元 | 价格按分校验；买入滑点价格向上取分、卖出向下取分 |
| 第 3.3.18 条：竞价申报当日有效 | v0.1 采用一日订单；当天不能成交即记录拒绝，不跨日保留旧订单 |

上述条款以官方附件为依据；本项目并未实现交易所完整撮合规则、申报价格笼子、所有单笔/单日申报数量限制、盘后交易或风险警示专门要求。沪深代码格式支持也不等于沪深交易制度已完成全面法律或业务验收；未来扩大执行范围时需分别复核各交易所和生效日期。

**ST 股票不能永久固定为 5%。** 上交所官方修订说明明确：主板风险警示股票涨跌幅限制由 5% 改为 10%，新规则从 2026-07-06 实施。历史模拟不能把新比例倒推到此前日期，也不能把普通主板、不同板块、上市特殊日期混为一类。因此程序要求逐证券、逐日的实际上下限价格。[上交所修订说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20260424_10816474.shtml)

公司行动、涨跌停、停复牌和日历属于执行事实；没有这些事实时，程序选择阻断。日线只说明全天聚合结果，不能证明开盘时任意数量都能成交，也不能还原封单队列、撤单、排队或日内流动性。

## 3. 费用是需要确认的固定情景

`cost_model_acknowledged` 默认 `false`。回测/纸面交易要求使用者明确确认后，才采用以下可调整的固定情景；这些数值不是券商报价或历史费率数据库。

| 参数 | 默认值 | 本项目计算方法 |
| --- | --- | --- |
| `commission_rate` | `0.0003`，即 0.03% | 买卖双边：成交金额 × 费率，并与最低佣金取较大值 |
| `min_commission` | 5 元 | 每笔最低佣金；按情景参数处理 |
| `stamp_tax_rate` | `0.0005`，即 0.05% | 仅卖出计提 |
| `transfer_fee_rate` | `0.00001`，即 0.001% | 买卖双边计提 |
| `slippage_bps` | 5 个基点，即 0.05% | 买入向不利方向上调开盘价，卖出向不利方向下调开盘价 |

佣金、印花税和过户费各自四舍五入到人民币分，再计入现金账；滑点影响成交价格，不重复作为一笔独立手续费。最低佣金和参数适用范围需要使用者自行确认。调整任何参数会改变结果参数和结果指纹。

历史税费确实会变动，例如财政部、税务总局公告规定自 2023-08-28 起证券交易印花税减半征收。这证明不能把今天选择的常数当成所有历史日期的真实费率。v0.1 未实现按日期、券商、账户和交易类型切换费率的历史账本。[财政部公告](https://m.mof.gov.cn/czxw/202308/t20230827_3904226.htm)

## 4. 本地回测的可解释情景

以下是本项目的实现选择，不是交易所关于真实成交的保证：

- 短、长均线只读取前一交易日及以前的原始收盘价，下一日按开盘价加不利滑点尝试成交；不使用当前日收盘价生成同日开盘信号。
- 每天重算持有/现金目标；只做多、不融资、不做空。订单被拒绝后，不把旧订单无限顺延。
- 上涨至开盘涨停阻止买入，下跌至开盘跌停阻止卖出；没有把两个方向都一概禁止。停牌、零量、滑点后价格越界或数量超过当日总成交量则整单拒绝，不做部分成交。
- 尚未建立成交参与率、盘口或市场冲击模型；数量不超过全日成交量只是粗略上限，不能证明开盘可成交。
- 均线预热会影响实际评价起日；策略与买入持有基准使用同样的评价日期、初始资金、费率和执行约束。
- 基准从首个评价日尝试买入，若被阻断则逐日重新尝试，首次成功后持有；它不是忽略涨跌停、费用和整手约束的理想价格曲线。
- 期末持仓按原始收盘价计值，不伪造强制平仓，不扣除尚未发生的卖出费用。
- 已知公司行动、未知关键字段或因子变化阻断相关执行区间。研究摘要不产生“AI 胜率”、推荐评级或确定收益。

均线不读取未来价格，只能证明这一计算环节的时序约束；它不证明数据源具备历史时点版本，也没有解决幸存者偏差、事后挑选参数或样本外有效性。

## 6. 合成样本与验收边界

仓库 `examples/` 为 140 个合成开市日、2 个示例代码的虚构样本。演示日历没有扣除中国节假日；演示涨跌停价也是构造数据，不能反过来证明固定 10% 是通用历史规则。

本轮可以报告本地单元测试、HTTP/界面检查和 mock 适配测试的实际结果；不能报告真实供应商鉴权已通过、真实股票历史已校验、模型产生可投资收益或券商交易已验证。真实数据接入验收应单独记录账户权限验证、响应证据、日历/停复牌/公司行动覆盖、样本核对和仍存的限制。
