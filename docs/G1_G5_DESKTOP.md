# Invest 0.2.0-rc1 Windows 使用说明

本程序是人民币主板研究与人工历史复盘工具，**不连接券商，不自动下单**。

1. 解压整个便携包到可写目录，例如 `D:\Invest-App`，不要只复制EXE而漏掉 `_internal`。
2. 启动 `Invest.exe`，通过桌面控制器打开本机工作台。根页面是G1–G5新界面；左下角链接保留旧版CSV导入、日频回测和历史模拟交易。
3. 第一次使用先点“载入合成演示”。该数据完全虚构，只验证功能。
4. 假设比较必须确认演示成本。没有完整交易日历、公司行动和执行字段的数据可能不能回测，程序不会补造这些字段。
5. 新复盘账本是人工声明，不是券商成交。买卖记录之后需要完整MARK估值；入金不是利润。
6. 关闭时通过桌面控制器停止服务。私人数据保存在控制器显示的本地数据目录，不会自动上传。
7. 完整备份在“档案与恢复”页导出，必须确认包含私人数据。恢复只创建新目录，不覆盖已有文件。

## 包身份

`SOURCE_COMMIT.txt` 是本包编译时的GitHub源码提交，`PACKAGE_MANIFEST.json` 记录文件身份和原生验证情况。只有本轮构建日志和产物匹配时，才称为本轮Windows包。2026-09-25的历史EXE不包含这次G1–G5能力。

CI实际Windows进程和浏览器验证成功，不意味着你的电脑已经实测。杀毒软件提示、系统权限和用户设备兼容性仍需在你的设备确认。不要以关闭操作系统安全功能作为默认安装步骤。

核心不依赖美元、GPU或模型服务。可选AKShare/Tushare真实数据仍需网络、数据权限及来源验证；打包未包含AKShare时，使用源码模式安装可选组件。未安装的组件会明确显示不可用，不偷偷切换数据源。

软件不承诺盈利或收益率；演示、历史回测、人工复盘和真实前向观察是四种不同证据。
