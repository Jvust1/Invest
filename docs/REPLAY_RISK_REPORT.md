# 固定配置净值 → 日收益 → 风险报告闭环

`invest.replay_risk.compare_allocation_risk_report(history, sizing_request, as_of="YYYY-MM-DD")` 把 PR #16 的固定配置账务回放和风险指标合同连接成一个 fail-closed 闭环：

```text
离散配置
→ Invest 自有现金/持仓/净值曲线
→ bt 1.2.3 独立账务回放
→ 逐日现金/持仓/净值/费用一致
→ 费用感知的日简单收益
→ QuantStats 0.0.86 + Empyrical Reloaded 0.5.12
→ 六项标准风险/绩效报告
```

## 收益口径

首个观测日不是直接记为 0。它使用：

`(首日买入后净值 / 初始资金) - 1`

因此最低佣金、佣金和过户费等**已实际发生的入场费用**会作为首日收益拖累保留下来。由于配置日、报价日和首个价格观测日必须一致，首日价格变动为零时，该收益恰好等于 `-入场费用 / 初始资金`。

第二个观测日起使用：

`(当日净值 / 前一观测日净值) - 1`

当前固定配置没有外部现金流、股息、利息或后续订单。期末不强制卖出，因此未发生的卖出税费不会提前计入收益。

## Fail-closed 条件

- Invest 与 bt 任一观测日的现金、持仓、净值或费用比较为 `DISAGREE`：拒绝生成风险报告。
- 风险报告少于 30 个共同净值观测：拒绝生成。
- 首日收益不能精确反映入场费用：拒绝生成。
- QuantStats / Empyrical 缺失、返回不完整或应定义指标出现非有限值：拒绝伪装成成功。
- 两个风险库计算结果超出容差：保留 `DISAGREE` 原值和差异，不自动选边。

## 标准报告

风险层输出累计收益、年化收益、年化波动率、最大回撤、零无风险利率 Sharpe、零目标收益 Sortino。全现金情景合法：累计/年化收益、波动率、回撤为 0；Sharpe 和 Sortino 标为 `UNDEFINED`，而不是伪造 0 比率。

## 验证

专用 CI 同时安装固定版本 `bt==1.2.3`、`quantstats==0.0.86`、`empyrical-reloaded==0.5.12`，使用 40 个合成交易日跑完整闭环，并单独覆盖全现金情景。基础测试继续在无可选依赖时通过 mock 验证费用口径、少样本和回放分歧的 fail-closed 行为。

这些合成价格只验证软件合同，不是市场收益证据。真实行情许可、公司行动、停复牌、历史规则、Hikyuu/Zipline、冻结 holdout 和前向观察仍是后续独立 gate。
