# Drive Github folder sources

The Drive folder contains a pinned source snapshot at
03_Invest_full_source_20260925.zip. Its manifest identifies eight projects and
their exact revisions. Invest uses the snapshot as provenance evidence, while
only license-compatible, bounded adapters enter the runtime.

The first runtime adapter is invest.providers.akshare_eastmoney, derived from
AKShare's stock_zh_a_hist implementation for Eastmoney A-share daily history.
Projects with AGPL, GPL, Commons Clause, or custom commercial restrictions stay
reference-only until their license and distribution model are intentionally
approved.
