# Invest Windows 桌面交付候选版

解压整个便携包，再运行 Invest.exe；不要单独搬走 EXE 或 _internal 文件夹。无需另装 Python；默认使用已安装的 Edge 应用窗口，缺少 Edge 时尝试系统浏览器。控制窗口退出时停止本机服务。

## 实际功能
人民币 A 股研究、CSV 与交易日历导入、来源及数据检查、含交易费用的简单均线策略回测、基准对比、T+1/整手等模拟约束、模拟账户与研究笔记。增加完整 SQLite 备份与只恢复到新目录的工具。没有真实券商/实盘下单功能。

## 数据和恢复
新桌面版数据位于 `%LOCALAPPDATA%\InvestDesktop\data`，不会自动搬动旧 `.invest` 数据。升级请保留该目录并先备份。
页面末尾“导出完整私人备份 ZIP”包括本机已导入行情、模拟账户、交易与私人笔记，请安全保管。
恢复必须使用一个不存在的新目录：
```
Invest.exe --restore-backup "D:\备份\invest-private-backup.zip" --data-dir "D:\Invest-恢复副本"
```
恢复后程序打开该副本。原目录不会被覆盖；再次打开副本使用 `Invest.exe --data-dir "D:\Invest-恢复副本"`。

## 严格边界
默认示例是合成数据，不是实时行情；默认费用是待核对的情景参数，不承诺适用所有证券或当前收费。真实数据需要你的数据授权与口径校验；本轮没有调用真实行情服务、没有完成持有集或样本外实证，不代表策略有效或收益保证。真实数据闸门和冻结评估证据保留。
